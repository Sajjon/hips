# `hip-0100` - Show remaining movement in the Hero Screen

> **Category:** Hero UI

Display the viewed hero's remaining `movement points` as a persistent numerical value in the **Hero Screen**, without requiring the player to hover over a movement indicator.

Use the hero's current [adventure-map movement state](https://heroes.thelazy.net/index.php/Movement), including whether the hero is on land or in a boat. Refresh the value when the viewed hero changes or a relevant effect changes their remaining points. Show it for the player's heroes without exposing hidden movement information about opponents.
