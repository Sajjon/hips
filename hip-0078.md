# `hip-0078` - Sort backpack artifacts alphabetically

> **Category:** Hero UI — artifacts

Add a **Sort alphabetically** button to the hero's `backpack`. Order carried artifacts by their localized displayed names and place identical names together, making duplicates and named items such as the `Grail` easier to find.

Apply the order only to the backpack's presentation; retain every artifact and leave equipped artifacts unchanged. When the grouping from [`hip-0012`](hip-0012.md) is active, alphabetize within each group; when grouping is off, alphabetize the whole backpack. The acquisition-order option from [`hip-0013`](hip-0013.md) must remain available.

This adds name ordering, which is distinct from grouping artifacts by class or combination.
