# `hip-0070` - Jump to map coordinates from object search

> **Category:** Adventure Map UI

> [!IMPORTANT]
> **Depends on:** [`hip-0069`](hip-0069.md)

Add coordinate entry to the **Find Object** dialog from [`hip-0069`](hip-0069.md). Accept a map coordinate with horizontal position, vertical position, and surface or underground level, using the same coordinate convention as the target build's map display.

After explicit confirmation, center the **Adventure Map** on the specified tile and switch levels if needed. Explain the accepted format beside the field. Reject out-of-bounds coordinates and an underground level on a one-level map without changing the viewed location.

This is camera navigation only. Preserve the selected hero and route, and retain normal `shroud` and fog of war at an unexplored coordinate.
