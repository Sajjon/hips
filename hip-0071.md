> **Category:** Adventure Map UI

Include **Eye of the Magi** and **Shipyard** as searchable object categories in the **Find Object** dialog from [`hip-0069`](hip-0069.md), alongside its other adventure-map object categories.

List discovered [Eyes of the Magi](https://heroes.thelazy.net/index.php/Eye_of_the_magi) and adventure-map [Shipyards](https://heroes.thelazy.net/index.php/List_of_adventure_map_objects) on either map level. Selecting a result centers the map there using the dialog's normal navigation behavior. Preserve the player's current information boundaries; an undiscovered eye must not reveal its location or the area it would illuminate.
