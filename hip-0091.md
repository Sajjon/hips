# `hip-0091` - Preview routes through known portals

> **Category:** Adventure Map UI

While using the existing `Alt`-hover movement-cost preview, holding `Ctrl` as well must calculate a route that can use known `Monolith` and `Subterranean Gate` connections. Display the resulting movement cost and the portal transitions used, so the player can compare it with the ordinary route.

Follow the game's [portal connection rules](https://heroes.thelazy.net/index.php/Map_Editor_-_Objects#Subterranean_Gate,_Monolith_and_Whirlpool), direction restrictions, accessibility, and actual movement costs. Use only connections and terrain already known to the player. When an exit is not deterministically selectable, identify the uncertainty instead of promising one exact destination or cost.

This modifier previews a route without executing it, teleporting the hero, or changing portal behavior.
