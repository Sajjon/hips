# `hip-0061` - Filter `Town Portal` by town type

> **Category:** Adventure Map UI

Add one filter button to the **Town Portal** destination dialog for each distinct [town type](https://heroes.thelazy.net/index.php/Town) the current player owns. Label each button with its town type, such as **Stronghold** or **Dungeon**. Determine which buttons to show from town ownership when the dialog opens, including owned towns that are currently unavailable as destinations.

For example, if the player owns one `Stronghold` and one `Dungeon`, show **Stronghold** and **Dungeon** buttons. Show no **Castle** button unless the player also owns a `Castle`. Owning several towns of the same type still produces only one button for that type.

Clicking a town-type button immediately shows only entries of that type from the normal destination list, preserving their relative order. Only one town-type filter can be active at a time; clicking another type replaces it. Clearly indicate the active button and provide an **All** button that clears the town-type filter. Start each newly opened dialog with **All** active. This makes it easier to visit towns of the same type to collect troops.

Button availability depends on the player's own towns. Filtering still operates on the normal destination list, including allied towns where normally listed. Keep each town's normal availability state: the filter must not make a town with a `visiting hero` eligible. Preserve the [normal `Town Portal` casting rules](https://heroes.thelazy.net/index.php/Town_Portal).

After changing the filter, retain the selected destination only if it remains visible and eligible; otherwise clear the selection and require the player to select a destination. Filtering must not cast the spell or close the dialog. If there are no matching entries, show an empty list and keep confirmation unavailable.

When combined with [`hip-0060`](hip-0060.md), apply its current-town scroll anchor and fallback rules within the filtered list after each filter change. When combined with the text search from [`hip-0010`](hip-0010.md), show only towns matching both the selected type and the search text; **All** clears only the type filter. This proposal can be implemented independently of both.
