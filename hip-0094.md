# `hip-0094` - Track learnable spells in a wishlist

> **Category:** Spell Book UI

Add a **Wishlist** page to the selected hero's **Spell Book** listing spells that the hero has not learned but that are known to be available from the player's towns or from friendly heroes through `Scholar`. Show each spell's source and the requirements for learning it.

Use only information the player already has about those sources. Distinguish a spell that can be learned now from one blocked by `Wisdom`, `Scholar` proficiency, or another normal rule. For teaching heroes, apply the [Scholar exchange limits](https://heroes.thelazy.net/index.php/Scholar); a source's possession of a spell alone does not guarantee that it can be transferred.

Refresh the page when the hero learns a spell, source availability changes, or relevant skills change. Selecting a source may show its known location without moving the hero or teaching the spell automatically.
