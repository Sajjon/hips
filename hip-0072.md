# `hip-0072` - Find enemy heroes and towns separately

> **Category:** Adventure Map UI

> [!IMPORTANT]
> **Depends on:** [`hip-0069`](hip-0069.md)

In the **Find Object** dialog from [`hip-0069`](hip-0069.md), add an **Enemy only** ownership filter for the **Heroes** and **Towns** categories. Enable it by default for those categories, since the player's own heroes and towns can already be cycled with `H` and `T` on the **Adventure Map**.

With **Enemy only** active, show enemy-controlled entries whose locations are currently available to the player. Let the player clear it to include other normally searchable ownership states, including owned, allied, or neutral entries as applicable. Switching categories must leave unrelated object searches usable.

Use the normal [hero and town controls](https://heroes.thelazy.net/index.php/Keybinds) as the navigation precedent. This changes **Find Object** results; [`hip-0055`](hip-0055.md) separately addresses **View World** markers and navigation. Never reveal a hidden enemy location.
