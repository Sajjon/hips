# `hip-0056` - Jump to View World locations with right-click

> **Category:** View World UI

In **View World**, allow the player to right-click any location in the map area to close **View World** and center the normal **Adventure Map** on the corresponding map tile. This must work at every **View World** zoom level and when the click lands on an object marker as well as on empty terrain.

Use the surface or subterranean level currently displayed in **View World**. If necessary, switch the **Adventure Map** to that level before centering it. Near a map edge, position the camera as close as possible while keeping the clicked tile visible.

The action changes only the viewed location. Preserve the currently selected hero or town and any plotted movement route; do not select an object, move a hero, or issue any other gameplay command.

Allow navigation to every map tile, including unexplored locations. Returning to an unexplored location must show the normal `shroud` or fog of war on the **Adventure Map** and must not reveal its terrain, objects, heroes, or any other hidden information.

Apply this behavior only when right-clicking inside the **View World** map area. Right-clicking zoom buttons, legend entries, filters, or other interface controls must retain their existing behavior. Closing **View World** with `Esc` or its existing confirmation control must continue to return without changing the **Adventure Map** position.
