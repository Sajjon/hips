# `hip-0089` - Open the Spell Book from the Hero Screen with `C`

> **Category:** Hero UI

While the **Hero Screen** has focus, pressing `C` must open the displayed hero's **Spell Book**, matching the keyboard access available from the **Adventure Map**.

Follow the same interaction as clicking that hero's spell book in the screen, including the normal availability and casting restrictions. A hero without a [Spell Book](https://heroes.thelazy.net/index.php/Spell_Book) must not acquire one or spend gold through this shortcut. Closing the book returns to the same hero unless the existing casting flow requires another screen.

Consume the keypress so it cannot also trigger an action on the underlying **Adventure Map**.
