# `hip-0098` - Page through teleport destinations

> **Category:** Adventure Map UI

In the **Town Portal** and `Castle Gate` destination lists, support `Page Up` and `Page Down` to move the selection by one visible page. Keep the reached entry visible, skip disabled destinations, and stop at the list boundaries.

Operate on the current results, including the name filter from [`hip-0010`](hip-0010.md) and town-type filter from [`hip-0061`](hip-0061.md) when present. Update the selected town's normal minimap highlight without casting, teleporting, or closing the dialog; confirmation remains a separate action.

This adds page navigation beyond the single-entry arrow controls in [`hip-0051`](hip-0051.md). The comment's keyboard-search request is already covered by [`hip-0010`](hip-0010.md).
