# `hip-0055` - Filter View World objects and cycle enemy heroes

> **Category:** View World UI

Add visibility controls to the **View World** legend so the player can independently show or hide each displayed category of object. At minimum, provide controls for **Heroes**, **Towns**, **Artifacts**, **Mines**, and **Resources**, together with every other object category that already has its own marker or legend label. Disabling a category must hide only its markers and labels; it must not hide terrain, alter the map, or change which locations the player has discovered.

Show clearly whether each category is enabled, for example with a checkbox or highlighted marker beside its label. All categories remain enabled by default. Filter changes are presentation-only and must not reveal objects hidden by the `shroud`, fog of war, or the player's current information sources.

Make the **Heroes** label a navigation control in addition to giving **Heroes** its separate visibility control. Repeatedly clicking the label must cycle through enemy heroes whose positions are currently available to the player, center the **View World** map on each hero in turn, and wrap from the last hero back to the first. This should feel like repeatedly pressing `H` or `T` on the normal **Adventure Map**, except that it remains inside **View World** and cycles visible enemy heroes rather than selecting the player's own heroes or towns.

If the next enemy hero is on the other map level, automatically switch between the surface and subterranean levels before centering the view. If the **Heroes** category is hidden, clicking its label must first show the category and then center the next enemy hero. When no enemy hero is currently visible, leave the map position unchanged and show a brief message such as **No enemy heroes are visible**.

Only cycle heroes already disclosed by normal vision, `View Air`, or another existing game effect. The feature must never reveal an undiscovered enemy hero, its army, or any other private information.
