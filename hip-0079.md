# `hip-0079` - Open both backpacks during hero exchanges

> **Category:** Hero UI — artifacts

Add a **Backpacks** button to the **Hero Trade Screen** that opens both heroes' carried artifacts together, allowing direct transfers between their backpacks without repeatedly opening one hero's inventory at a time.

Keep each artifact visibly associated with its current holder. Support the same valid manual transfers as the normal exchange interface, including normal destination-capacity rules, and refresh both inventories immediately after a transfer. Closing the backpack view returns to the same hero exchange.

Preserve existing [artifact exchange controls](https://heroes.thelazy.net/index.php/Keybinds#Hero_Trade_Screen). This concerns two heroes meeting; [`hip-0024`](hip-0024.md) addresses backpack access in selling and sacrifice interfaces.
