# `hip-0051` - Navigate every list with arrow keys

> **Category:** Global UI

Make `Up Arrow` and `Down Arrow` navigate every selectable list in the game and the *HD Mod* interface. `Up Arrow` must select the previous selectable entry and `Down Arrow` must select the next one. Move by one entry per keypress, scroll as needed to keep the new selection visible, and skip disabled or otherwise unselectable entries.

Apply the keys to the focused list. If a dialog contains exactly one list, treat it as focused even before the player clicks an entry. When no entry is selected, `Down Arrow` must select the first selectable entry and `Up Arrow` the last. At either end, stop unless that specific list already wraps when navigated by its existing controls. Navigate only the entries currently present after filtering or searching.

In particular, the **Town Portal** destination list must no longer ignore these keys. Moving the selection with `Up Arrow` or `Down Arrow` must update the selected town and its minimap highlight exactly as clicking that entry would. The keys must not cast `Town Portal` or close the dialog; the player must still confirm the selected destination through the existing action. Apply the same behavior to the `Inferno` `Castle Gate` destination list and to the filtered results introduced by [`hip-0010`](hip-0010.md).

While **Kingdom Overview** is displaying **Town Information**, the keys must continue to move to the previous or next town without opening the corresponding **Town Screen**. Match the existing **Scroll Up** and **Scroll Down** controls and keep the reached town visible. While **Hero Information** is displayed, apply the same general rule to its selectable hero list.

Preserve established arrow-key behavior outside lists. For example, `Up Arrow` and `Down Arrow` continue to cycle towns in the **Town Screen**; [`hip-0050`](hip-0050.md) separately applies the same keys to heroes in the **Hero Screen**; and `Left Arrow` and `Right Arrow` retain the two-choice activation behavior defined by [`hip-0049`](hip-0049.md). Consume a list-navigation keypress so it cannot also affect the screen behind the active dialog.
