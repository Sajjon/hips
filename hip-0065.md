# `hip-0065` - Page through saved games with the keyboard

> **Category:** Main menu UI

In the **Load Game** saved-game list, support `Page Up`, `Page Down`, `Home`, and `End`. The page keys move the selection by one visible page; `Home` selects the first entry and `End` the last. Scroll to keep the selection visible and stop at the list boundaries.

Navigate the currently displayed order and filtered results, including sorting introduced by [`hip-0002`](hip-0002.md). These keys must only change selection; loading still requires the normal confirmation. Handle the keys while the list has focus without changing text in a focused filename or search field.

This supplements the single-entry arrow navigation in [`hip-0051`](hip-0051.md).
