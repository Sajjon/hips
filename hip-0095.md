# `hip-0095` - Sort the town list by town type

> **Category:** Adventure Map UI

Add a **Sort by town type** option to the player's main **town list**. Group all owned towns of each [town type](https://heroes.thelazy.net/index.php/Town) together so the player can recruit or construct buildings in successive towns of the same type.

Preserve the relative order within each type and provide a way to return to the player's previous list order. Keep the selected town selected after sorting. Actions that cycle through this list must follow the displayed order.

This sorts the main town list; [`hip-0061`](hip-0061.md) separately filters the **Town Portal** destination dialog.
