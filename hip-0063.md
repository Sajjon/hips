# `hip-0063` - Locate quest targets with right-click

> **Category:** Adventure Map UI

When right-clicking a quest-giving or quest-blocking object on the **Adventure Map**, offer the same target-location navigation available for its entry in the **Quest Log**. Apply this to `Seer's Huts`, `Quest Guards`, and `Quest Gates` where the quest has a locatable target.

Center the map on the target and switch map levels as needed, preserving the selected hero and movement route. Use exactly the information available through the **Quest Log**: a quest that does not disclose a target's location must not reveal it through this shortcut. Leave the existing quest description available, including for resource or creature requirements without a unique target location.

Use the [quest system's existing requirements](https://heroes.thelazy.net/index.php/Seer%27s_Hut); this shortcut changes access to known quest information.
