# `hip-0085` - Select `Tactics` stacks without opening details

> **Category:** Combat UI

During the `Tactics phase`, left-clicking a movable friendly stack must select it for placement. Clicking an already selected stack must keep it selected instead of opening its creature information window, allowing repeated selection and movement clicks without an intervening details popup.

Keep right-click available for creature information. Clicking a legal destination moves the selected stack according to the normal [Tactics deployment rules](https://heroes.thelazy.net/index.php/Tactics); clicking a stack or its occupied hex must not end the phase. Retain existing left-click behavior after the deployment phase finishes.
