# `hip-0075` - Copy the combat log to the clipboard

> **Category:** Combat Log UI

Add a **Copy to clipboard** button to the **Combat Log**. Copy the full log for the current battle as readable plain text, including entries outside the visible scroll area, so the player can search or retain it in a text editor.

Preserve line breaks, round headings, and stack identifiers when those features are available. If [`hip-0040`](hip-0040.md) is implemented, copy the entries shown by the selected **Info / Verbose** detail level. Give brief confirmation after a successful copy and report a clipboard failure without closing the log.

This export uses the information already available in the player's log and does not require the structured notation from [`hip-0041`](hip-0041.md).
