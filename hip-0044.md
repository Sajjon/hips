# `hip-0044` - Add thousands separators to all numbers

> **Category:** Global UI

Display every numerical quantity of `1,000` or more with a thousands separator everywhere it appears in the game and the *HD Mod* UI. Apply the formatting consistently to values including current and required `experience`, resources and costs, creature quantities, damage, health, spell points, movement points, scores, rewards, and statistics in all screens, dialogs, tooltips, and logs.

Group digits in sets of three from the right, using the separator appropriate to the selected language. For example, English must display `1234` as `1,234` and `123456789` as `123,456,789`. Never abbreviate or round a value, and do not change its stored value or any calculation; this proposal changes only how numbers are displayed.
