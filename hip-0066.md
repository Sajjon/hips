# `hip-0066` - Open boat hero exchanges with movement keys

> **Category:** Adventure Map UI

Allow the directional keyboard controls used to move a hero to initiate an exchange with a reachable friendly hero in a `boat`, whenever clicking that same hero would normally open the **Hero Trade Screen**.

Resolve the same target, reachability, movement cost, and exchange restrictions as the mouse action. An occupied [boat](https://heroes.thelazy.net/index.php/Boat) remains occupied by its original hero: the shortcut opens the legal meeting interaction and does not put two heroes in one boat. If the exchange is not currently legal, retain normal movement-key behavior without starting an unintended action.
