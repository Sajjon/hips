# `hip-0050` - Cycle heroes with arrow keys

> **Category:** Hero UI

While the **Hero Screen** is open, pressing `Up Arrow` must display the previous hero and pressing `Down Arrow` must display the next hero without closing the screen. Mirror the existing **Town Screen** behavior, where the same keys cycle through the player's towns.

Follow the current hero-list order and match the **Town Screen**'s behavior at the beginning and end of its list, including whether navigation wraps. Refresh every hero-specific value, army slot, artifact slot, and available action for the newly displayed hero without changing any hero's state. Consume the keypress so it does not also affect the **Adventure Map** after the **Hero Screen** closes.
