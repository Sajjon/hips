Source: [Noumenon72's Reddit comment](https://www.reddit.com/r/heroes3/comments/1x5m2s1/comment/phneoo4/), by [Noumenon72](https://www.reddit.com/user/Noumenon72/). Reviewed on 2026-11-06 against all 61 existing proposal files, including their descriptions rather than catalogue titles alone.

The comment calls its list 49 suggestions, but its broken numbering produces 50 listed entries when read in order, including the repeated breath-attack preview. The review numbers below are normalized reading-order positions, not the comment's displayed labels. The three terrain-description entries are recorded separately so none is lost in the comparison.

Created 41 new proposals, [`hip-0062`](hip-0062.md) through [`hip-0102`](hip-0102.md). Six entries were conservatively skipped as covered or overlapping, two describe existing features, and one repeats another suggestion in the same comment. Existing proposals and their author credits are unchanged.

The initial request for a generated text list is repository feedback, outside the game's improvement-proposal scope. The proposed alternative lettering for battlefield coordinates concerns the existing [`hip-0038`](hip-0038.md); no competing coordinate HIP was created.

For review item 44, only page navigation is new. Destination text search is already covered by [`hip-0010`](hip-0010.md); the new proposal links to it rather than duplicating it.

The specialty request in item 18 is interpreted as the hero's **Specialty** icon on the **Hero Screen**, with the bonus calculated at that hero's level.

The source comment's `Ctrl+F` interface has a documented [SoD_SP FindMe precedent](https://heroes3wog.net/download/%5BManual%5D%20SoD_SP_Plugin_documentation.pdf). Its presence in the repository's target setup is not assumed: [`hip-0069`](hip-0069.md) provides the object-search interface for *Horn of the Abyss* with the *HD Mod* where absent, and [`hip-0070`](hip-0070.md), [`hip-0071`](hip-0071.md), and [`hip-0072`](hip-0072.md) depend on it. The [wiki's object catalogue](https://heroes.thelazy.net/index.php/List_of_adventure_map_objects) supplies canonical object names. This search dialog is distinct from the **View World** interface in [`hip-0055`](hip-0055.md).
