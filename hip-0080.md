# `hip-0080` - Select a hero when closing an exchange

> **Category:** Hero UI

In the **Hero Trade Screen**, pressing `1` must close the exchange and select the hero displayed on the left; pressing `2` must close it and select the hero on the right. Match the corresponding existing mouse action for closing the meeting and making that hero active.

Apply the shortcut only when the main exchange screen has focus. Number entry in an open stack-splitting dialog or another text field must retain its normal meaning. Preserve all completed trades and return to the normal view for the chosen hero without moving either hero or repeating an exchange action.
