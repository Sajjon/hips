# `hip-0043` - Show primary skills without artifacts

> **Category:** Hero UI — artifacts

In the **Hero Screen**, let the player hold `Ctrl` to temporarily display the hero's `Attack`, `Defense`, `Power`, and `Knowledge` values without any bonuses or penalties from equipped `artifacts`. Keep permanent primary-skill gains and modifiers from non-artifact sources in these values. Clearly label this view as **Without artifacts**, and restore the current total values as soon as `Ctrl` is released.

This preview must not unequip or move any `artifact`, so it remains available when the hero's `backpack` is full.
