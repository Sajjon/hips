# `hip-0049` - Activate two-choice dialogs with arrow keys

> **Category:** Global UI

In every dialog or message window with exactly two choices displayed side by side, pressing `Left Arrow` must immediately activate the left button, and pressing `Right Arrow` must immediately activate the right button, exactly as if the corresponding button were clicked.

Apply these shortcuts consistently to two-choice interfaces such as a `Treasure Chest` reward choice and the two `secondary skill` choices offered when a hero gains a level. Activation must not require a separate `Enter` keypress. Keep the existing mouse and number-key controls unchanged, and consume the arrow-key input so it does not also affect the underlying screen.
