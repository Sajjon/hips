# `hip-0097` - Track combination artifact components

> **Category:** Hero UI — artifacts

Add a **Combination artifacts** progress screen showing each [combination artifact](https://heroes.thelazy.net/index.php/Combination_artifact), its required components, and which components the current player already owns. Include artifacts equipped by or carried in the backpacks of the player's heroes, with the holder identified for every owned component.

Mark missing components clearly. Treat the components inside an already assembled combination artifact as accounted for and show that artifact as assembled. Keep distinct artifact instances separate so one item is not counted as two simultaneously available components.

Update progress after transfers, assembly, disassembly, acquisitions, and losses. This screen reports the player's inventory and must not reveal artifacts carried by opposing heroes or automatically move or assemble items.
