# `hip-0047` - Make identical costume artifacts interchangeable

> **Category:** Hero UI — artifacts

In the *HD Mod*'s `Costumes` feature, match each artifact in a saved `costume` by its `artifact type` rather than by the unique identifier of the particular artifact instance that was equipped when the `costume` was saved. Any two artifacts of the same type must be interchangeable when equipping a saved `costume`.

For example, if a saved `costume` contains a `Skull Helmet` and the hero later transfers that particular instance to a supporting hero while retaining another `Skull Helmet`, equipping the `costume` must use the remaining `Skull Helmet`. It must not leave the `head slot` empty merely because the originally saved instance is now held by another hero.

Use a distinct available instance for every saved slot when a `costume` contains the same artifact type more than once. Consider only artifacts equipped by or carried in the `backpack` of the selected hero; do not take artifacts from another hero. If the selected hero has fewer copies than the `costume` requires, equip as many as are available and retain the existing missing-artifact behavior for the rest.
