# `hip-0029` - Label every creature stack

> **Category:** Combat UI

Assign a stable, unique, single-character label to every `creature stack`: uppercase `A`–`T` for the attacking army and lowercase `a`–`t` for the defending army. Assign the next available label to every stack created during combat, including `Demons` summoned by `Pit Lords`, `Air Elementals`, `Earth Elementals`, `Fire Elementals`, and `Water Elementals` summoned by `spells`, and `Fangarms` raised by the `Horn of the Abyss` artifact. Annotate every `creature stack` with its label.

Render the label as part of the stack's battlefield presentation, not only in the **combat log**, a tooltip, or another secondary view. Place it immediately below the stack's hit-point bar and use the same font size as the visible creature-count number. Fill the letter with the same blue-purple color used behind that number and add a white outline around the glyph so it remains legible against every battlefield background.

![Proof of concept showing stack labels below the hit-point bars](assets/hip-0029-stack-labels-poc.png)

Use the same label wherever the stack is named. For example:

* “Jotunn Warlords (`C`) take a defensive stance and gain +25 `Defense Skill`.”
* “Trolls (`b`) regenerate 40 hit points.”
* “War Mammoths (`D`) reach `Rune Level 6`.”
