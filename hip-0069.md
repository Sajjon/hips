# `hip-0069` - Find adventure-map objects by name

> **Category:** Adventure Map UI

Provide a text-search field in an **Adventure Map** **Find Object** dialog. Typing an object type or a known object's displayed name must filter the results without requiring the player to identify its icon. Let the player select a result to center the map on it and switch map levels when needed.

Use `Ctrl+F` where it is available for this action in the target build; preserve any conflicting binding and expose the action through a visible control. The [SoD_SP FindMe dialog](https://heroes3wog.net/download/%5BManual%5D%20SoD_SP_Plugin_documentation.pdf) is a precedent, rather than an assumption that the same dialog is already built into *Horn of the Abyss* with the *HD Mod*. Supply the dialog in that setup if it is absent.

Respect the dialog's toggle for whether the search should reveal items in Uncharted Territory. Selecting a result changes the viewed location without moving a hero. This search is separate from the destination-name filter in [`hip-0010`](hip-0010.md).
