# `hip-0059` - Cast combat spells with dedicated shortcuts

> **Category:** Combat UI

Add fixed keyboard shortcuts that select specific combat `spells`, using only inputs that are unassigned in the active context. A shortcut must behave like clicking that spell in the **Spell Book**: enter normal targeting when a target is required, or perform the normal casting action for a spell without a manually selected target. Keep normal costs, casting limits, availability, immunities, and confirmations.

This is a simpler companion to [`hip-0058`](hip-0058.md). The player chooses a new target after selecting a targeted spell; no previous target, stack label, or movement history needs to be remembered. Reserve bare `X` for that proposal's repeat-cast action.

## Existing controls

The [Heroes 3 wiki's keybind list](https://heroes.thelazy.net/index.php/Keybinds#Combat_Screen) documents these occupied combat letters, including *Horn of the Abyss* and *HD Mod* additions:

| Key | Existing combat action |
| --- | --- |
| `A` | **Autocombat** |
| `C` | Open the **Spell Book** |
| `D` | **Defend** |
| `F` | Creature spell |
| `G` | Area attack or creature spell |
| `H` | Open the **Combat Log** |
| `I` | Toggle hero statistics |
| `L` | **Load Game** |
| `O` | **Combat Options** |
| `Q` | Finish with **Quick Combat** |
| `R` | **Retreat** |
| `S` | **Surrender** |
| `T` | Current troop information |
| `W` | **Wait** |
| `Z` | Toggle the **turn order bar** |

Keep these actions, including conditional creature controls, assigned to their existing keys. In particular, bare `S` and `F` cannot select `Slow` and `Force Field` directly on the battlefield. Use `Shift+S` and `Shift+F` in both contexts, with bare `S` and `F` as additional shortcuts only inside the **Spell Book**.

Inside the **Spell Book**, preserve `A` for the **Adventure spells** tab, `C` for the **Combat spells** tab, the arrow keys for existing book navigation, and `Esc` and `Enter` for closing it. Other battlefield letters can select spells while the book has focus. In particular, add `Q` for `Quicksand`, `I` for `Implosion`, `R` for `Resurrection`, `D` for `Shield`, and `H` for `Haste` there. Consume the keypress before closing the book so it cannot also trigger the battlefield action underneath it.

The proposed bare keys available in both contexts are `B`, `E`, `J`, `K`, `M`, `N`, `P`, `U`, `V`, and `Y`. The tables also use distinct `Shift` and `Ctrl+Shift` combinations when mnemonic letters are already assigned. These are proposed defaults based on documented controls, rather than a runtime audit of every game build. Preserve any additional binding in the target build; if a proposed input is already assigned there, leave that spell without that shortcut instead of replacing the existing action. Match modifiers exactly so a new combination never also invokes its bare-key action. Keep existing modifier-and-mouse controls working.

## Proposed spell bindings

The assignment of single-key, two-key, and three-key shortcuts reflects each spell's importance and prominence, favoring simpler inputs for prominent spells while preserving existing controls. Prefer recognizable letters from spell names; `J` for a lightning jolt and `V` for the velocity granted by `Haste` are descriptive alternatives. Spell names follow the [Heroes 3 wiki's spell list](https://heroes.thelazy.net/index.php/List_of_spells), and each spell below links to its page.

Group bindings by the number of modifier keys and sort spells alphabetically within each section. **Spellbook not opened** lists the shortcuts available on the battlefield; **Spellbook opened** lists all shortcuts available while the **Spell Book** has focus, including those also available on the battlefield. A dash means no shortcut for that modifier count in that context. A spell with a bare-key alias and a modified shortcut appears in both applicable sections. Unavailable spells do not free their keys for another spell.

## Casting behavior

Enable spell shortcuts only during the player's normal battlefield control and while the **Spell Book** opened from combat has focus. Keep them inactive during the `Tactics phase`, animations, automatic or opposing turns, chat/text entry, and other dialogs. Recognize lowercase and uppercase letters as the same key; `Shift` in a combination denotes an actual modifier, not capitalization or `Caps Lock`.

Inside the book, find the assigned combat spell regardless of its current page or school filter. The shortcut selects that spell directly, without requiring it to be visible. It must never select an Adventure Map spell. Show the applicable shortcuts on spell entries or their tooltips, including any book-only alias.

If the hero does not have the spell, cannot currently cast it, or cannot make any legal cast of it, the shortcut does nothing: keep the current screen and selection, spend no `spell points`, and consume no hero casting opportunity or creature action. Never fall through to a battlefield action after an unavailable spell shortcut is handled in the book.

For a targeted spell, close the book if necessary and show its normal targeting cursor. Preserve ordinary target validation and cancellation with `Esc`; spend resources only when the normal casting action commits. For mass, random-placement, or other spells without a manually selected target, follow their existing casting flow. `Titan's Lightning Bolt` is available only when the hero normally has access to it through `Titan's Thunder`.

Each physical keypress may select or cast at most once; holding the key must not repeatedly cast through keyboard auto-repeat. A spell actually cast through these shortcuts becomes the previous cast for [`hip-0058`](hip-0058.md), if that proposal is implemented. Merely selecting or canceling a spell does not update the previous cast. This proposal can be implemented independently.
