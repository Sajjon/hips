# `hip-0104` - Show the scenario name for AUTOSAVE

> **Category:** Main menu UI

Show the saved scenario's name when the player selects `AUTOSAVE` in **Load Game**, using the same scenario-name field and presentation as other saved games. Currently, `AUTOSAVE` omits this information, even though the *HD Mod*'s automatically saved `BATTLE` file shows it. The player should be able to identify which scenario an autosave belongs to before loading it.

Read the scenario name from the selected save, including when browsing saves from the main menu before any scenario has been loaded. Whenever `AUTOSAVE` is overwritten by a different scenario, its displayed scenario name must reflect that new save. Apply the same presentation in **Save Game** wherever the selected save's scenario details are shown.

Keep the filename `AUTOSAVE` and its existing automatic-save timing and overwrite behavior. This proposal adds the missing scenario information to the interface.
