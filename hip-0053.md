# `hip-0053` - Persist costumes in saved games

> **Category:** Hero UI — artifacts

Store the *HD Mod*'s player-defined `costumes` as part of each saved game's data. Persist every manually saved `costume` slot (`1`–`9`), including its artifact types and their equipment slots, as the definitions exist when the game is saved.

When a saved game is loaded, restore its `costumes` before any `costume` hotkey can be used. This must also work after the player quits the application completely, restarts it, and loads the saved game: each restored shortcut must equip the same artifact arrangement that was stored in that save. Because *HD Mod* `costumes` are player-wide rather than hero-specific, keep each set of slots scoped to its player.

Loading a saved game must replace any `costume` definitions remaining in memory from another game or session with the definitions stored in the loaded save. For backward compatibility, saved games created before this feature was introduced must still load successfully; no `costumes` are restored when the save contains no `costume` data.
