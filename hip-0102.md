# `hip-0102` - Prefill saves with the last saved filename

> **Category:** Main menu UI

When opening **Save Game**, prefill the filename with the name of the most recent successful manual save rather than the name of the most recently loaded file. Loading an earlier save must not overwrite the remembered manual-save name.

For example, after saving `144a` and then `144aa`, loading `144a` must leave `144aa` as the next save dialog's initial filename. The player can append another letter or replace the name normally.

Update the remembered name only after a manual save succeeds. Canceled or failed saves and automatic saves must leave it unchanged. Before any manual save in the session, use the existing filename fallback. Preserve normal overwrite confirmation.
