# `hip-0058` - Repeat combat spells with `X`

> **Category:** Combat UI

> [!IMPORTANT]
> **Possible dependencies:** [`hip-0029`](hip-0029.md) (stable stack labels) and [`hip-0039`](hip-0039.md) (tracking stack movements).
> Repeating a cast on the same stack after it moves may require the stack identification and movement tracking introduced by these proposals. Reuse that support where needed to keep the remembered target associated with the correct stack and its current position.

During combat, pressing `X` must repeat the most recent `spell` cast by the current player's hero on the same target, without reopening the **Spell Book** or requiring another target click. Prioritize `Resurrection` and damage-dealing spells that target a single `creature stack`.

Remember the spell and the identity of its target stack separately for each hero, for the current battle only. Follow that stack if it moves; do not target another stack that occupies its previous hex. Each newly cast spell replaces the remembered cast. Canceled targeting and rejected casting attempts must not replace it, and creature abilities or the opposing hero's spells must not overwrite it.

For example, after casting [`Magic Arrow`](https://heroes.thelazy.net/index.php/Magic_Arrow) on an `Ogre` stack, pressing `X` casts `Magic Arrow` on that same stack again if the cast is currently legal. If the stack has died, pressing `X` does nothing. Never select another `Ogre` stack or fall back to an earlier spell.

After casting [`Resurrection`](https://heroes.thelazy.net/index.php/Resurrection) on an `Arch Devil` stack, pressing `X` repeats `Resurrection` on that same stack while it remains a valid target with casualties to restore. Once the stack is fully resurrected, pressing `X` does nothing. A dead stack remains eligible only when normal `Resurrection` targeting rules allow its corpse to be targeted.

Check the current battle state before every repeat. Apply normal spell availability, `spell points`, casting limits, targeting restrictions, and immunities. If there is no previous cast, the hero cannot currently cast, or the remembered target is invalid, `X` must be a no-op: spend no `spell points`, consume no casting opportunity or creature action, and open no dialog or targeting mode. Keep the remembered cast so it can be repeated later if it becomes legal again. Do not queue a cast for a later turn. A legal repeat has the same cost and resolution as a manual cast, including normal resistance rolls; it does not replay the previous damage or resurrection result.

Optionally support area-of-effect spells such as [`Frost Ring`](https://heroes.thelazy.net/index.php/Frost_Ring), [`Inferno`](https://heroes.thelazy.net/index.php/Inferno_(spell)), and [`Fireball`](https://heroes.thelazy.net/index.php/Fireball) by remembering the selected target hex. Repeat at that exact hex using the current occupants and normal spell footprint, including friendly fire; for `Frost Ring`, the center hex remains unaffected. This support may be deferred if it complicates implementation. If the most recent cast uses an unsupported targeting mode, `X` must do nothing rather than repeat an older supported spell.

Handle `X` only while the player controls the battlefield, outside the **Spell Book**, dialogs, and text entry. The shortcut must not issue a creature command.
