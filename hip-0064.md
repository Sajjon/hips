# `hip-0064` - Save and reuse `Tactics` layouts

> **Category:** Combat UI

During the `Tactics phase`, let the player save the current army placement as a named layout, keep several layouts, and designate one as the default for that hero. Store layouts by army slot, including each stack's occupied hexes and facing, and retain them in saved games.

Offer saved layouts during later `Tactics phases` and apply the default automatically when its entire placement is legal for the current army and battlefield. Validate stack size, obstacles, deployment area, and the effective [Tactics proficiency](https://heroes.thelazy.net/index.php/Tactics) after the opposing hero's skill is considered. If the full layout cannot be applied, retain the normal legal starting arrangement and explain which placements conflict.

Applying a layout must leave the player in the `Tactics phase` so placements can still be adjusted. A preset cannot grant a deployment phase or deployment area that the hero would not normally have.
