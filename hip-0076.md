# `hip-0076` - Read the combat log from battle results

> **Category:** Combat Log UI

Add a **Combat Log** action to the battle-results screen, including the **Victory** screen, so the player can review the completed battle before dismissing its results. Retain the log through the final attack, retaliation, spell effect, and other events that end combat.

Opening and closing the log must return to the same results screen with its rewards and outcome unchanged. Use the normal log presentation, scrolling, and any available detail controls. This concerns retaining access after the final action; [`hip-0039`](hip-0039.md) separately specifies which events are recorded.
