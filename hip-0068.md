# `hip-0068` - Preview movement bonuses from map objects

> **Category:** Adventure Map UI

When hovering over a discovered adventure-map object that grants `movement points`, show the bonus the selected hero would receive by visiting it now, along with its duration. Use the active *Horn of the Abyss* rules and the selected hero's current eligibility.

For example, the tooltip for [Stables](https://heroes.thelazy.net/index.php/Stables) should distinguish a newly available bonus from a bonus that the hero already has for the current week. If the visit would grant no additional movement, state that explicitly. Keep any other object effects visible in its normal information.

Calculate the bonus using the same rules as an actual visit, without applying it during inspection. This complements the terrain-cost preview in [`hip-0046`](hip-0046.md) and the automatic town bonus in [`hip-0005`](hip-0005.md).
