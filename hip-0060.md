# `hip-0060` - Scroll `Town Portal` to the current town

> **Category:** Adventure Map UI

When a hero currently visiting a town opens the **Town Portal** destination list, initialize its scroll position at that town. Place the current town at the top of the visible list where possible, clamping to the maximum scroll position near the end. Keep the existing town order.

Apply this each time the dialog opens, using the town the casting hero is currently visiting. This makes collecting troops from many towns more convenient: after teleporting to a town and picking up troops, reopening the list starts at that town's position, with subsequent towns readily accessible.

The current town remains subject to normal destination eligibility. If its entry is shown but disabled, still use it as the scroll anchor. If the list omits it, start at the first listed town after it in the existing town order, or at the end of the list if none follows. If the hero is not visiting a town, retain the existing initial scroll behavior.

This changes only the initial scroll position; preserve destination selection and confirmation behavior. The [normal `Town Portal` rules](https://heroes.thelazy.net/index.php/Town_Portal) still apply, including destination choice requiring `Advanced` or `Expert Earth Magic` and towns with a `visiting hero` being unavailable.
